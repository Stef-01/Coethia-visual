# How Does Politics Shape American Health?

A scrollytelling explainer arguing that American health behavior should be segmented
by belief and barrier rather than by party, and that doing so changes who counts as
reachable.

**[political-health-personas.html](political-health-personas.html)** — open it in a
browser. No build step, no server required.

---

## Every number in this piece is invented

This is a **design prototype**. The five personas, their shares, their engagement
scores, the 3,000-person sample and the three survey waves are all synthetic
placeholders, generated by a seeded pseudo-random function in the file itself. They
are constructed to be structurally plausible so the layout can be evaluated. They are
not survey results, they are not modeled estimates, and they must not be cited.

Where the copy says segmentation work "routinely reports" something about trust, that
is the premise the design assumes, not a result this prototype establishes. No
literature is cited because none is relied on: what is being tested is how you would
*segment* a population, and that argument stands or falls on its own logic.

The data schema is designed to be swapped for real survey output without changing any
layout code.

## How it is built

Vanilla HTML, CSS and JavaScript with D3 for layout and transitions. No framework and
no build step. Roughly 30 illustrations are drawn in code as inline SVG rather than
imported as assets.

The chart lives in a fixed viewBox that is scaled to fit, which is what makes the
camera moves between scenes possible. Because that scaling would otherwise shrink a
13-unit label to under 5 physical pixels on a phone, every chrome label carries its
base size and is multiplied by a type scale derived from the live render scale, so
labels hit real pixel targets at any width while desktop stays exactly as composed.

### Data invariants

Two rules the generator holds, and the chart depends on:

1. **Every demographic family partitions the same sample.** Gender, geography, race,
   party and income each sum to the stated 3,000.
2. **The bubble grid partitions the declared shares.** Summing a persona column
   reproduces its stated share, so the grid and the depth bands cannot disagree about
   which persona is largest.

Bubble area is population in both scenes, with no correction factor, so the five
persona bubbles a demographic bubble breaks into sum back to it.

## Accessibility

The chart is `role="group"` rather than `role="img"`, because an image is an atomic
leaf and this one contains real controls. The drawing layers are individually hidden
from assistive technology, leaving the chart summary, five focusable persona columns
and the data table as the accessible surface.

- Tab into the persona strip, arrow between columns, Escape to leave. Announced shares
  track the wave currently drawn.
- "Read the data as a table" carries every figure in the chart, as a real table.
- All motion honours `prefers-reduced-motion`, including the largest camera moves.
- Marks that encode a quantity animate without overshoot, so a band never briefly
  draws a share nobody has.
- The five persona colours and the party colours are checked for deuteranopia and
  protanopia separability.
